# Source Symbol Types

Select a type only from the section for the source language. Each section is
self-contained. Use lowercase values exactly as shown.

## TS and JS

| Type | Use for |
|---|---|
| `class` | A class declaration. |
| `interface` | A TypeScript interface declaration. |
| `enum` | A TypeScript enum declaration. |
| `enum-member` | A TypeScript enum member. |
| `type-alias` | A TypeScript type alias. |
| `function` | A named function declaration. |
| `method` | A class or object method. |
| `constructor` | A class constructor. |
| `property` | A declared property or accessor pair. |
| `field` | A public or private class field. |
| `variable` | A `let` or `var` declaration. |
| `constant` | A `const` declaration. |
| `namespace` | A TypeScript namespace declaration. |
| `module` | A named module declaration. |

| `constant` | A declared constant. |
| `macro` | A named preprocessor macro. |
| `concept` | A C++ concept declaration. |
| `namespace` | A namespace declaration. |
| `module` | A named module declaration. |

## Python

| Type | Use for |
|---|---|
| `class` | A class declaration. |
| `function` | A module or nested function. |

| `variable` | A named variable declaration. |

## Rust

|---|---|

| `union` | A union item. |
| `enum` | An enumeration item. |

| `type-alias` | A type alias item. |
